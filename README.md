# 🎮 NEX-metro Theme for Xenia Dashboard
This project is an authentic, fan-made recreation of the classic 2008-2011 Xbox 360 Metro/NXE interface. Please note that this is an external theme extension specifically designed for the Xenia Dashboard program. It aims to completely transform your existing dashboard into the golden era of console interfaces.

## ✨ Key Features | المميزات الرئيسية

| Features | المميزات |
| :--- | ---: |
| 🎨 **Near-Authentic Design:** Pixel-perfect Metro 2011 UI with dynamic hero backgrounds and classic Xbox sounds.<br><br>🖌️ **Fully Customizable:** The system is highly flexible, allowing anyone to build, modify, and create their own custom interfaces exactly as they wish.<br><br>🎮 **Full Controller Support:** Seamless navigation using Gamepad or Keyboard.<br><br>📚 **Smart Library:** Auto-fetching of game metadata, covers, and backgrounds via SteamGridDB/LocalDB.<br><br>🏆 **Achievements Tracker:** Built-in system to track your Xbox 360 achievements with a beautiful split-pane UI.<br><br>⚙️ **Advanced Configuration:** Per-game configuration, deep binary scanning (via abgx360), and patch management.<br><br>🌍 **Localization:** Full support for multiple languages, including Right-to-Left (RTL) Arabic layout. | <div dir="rtl">🎨 **تصميم شبه الأصلي:** واجهة Metro 2011 مطابقة تقريباً للأصل مع خلفيات ديناميكية وأصوات الإكس بوكس الكلاسيكية.<br><br>🖌️ **تخصيص كامل:** نظام مرن يتيح لأي شخص بناء، تعديل، وإنشاء واجهته الخاصة (Themes) وتخصيصها تماماً كما يريد.<br><br>🎮 **دعم كامل للتحكم:** تنقل سلس باستخدام ذراع التحكم (Gamepad) أو لوحة المفاتيح.<br><br>📚 **مكتبة ذكية:** جلب تلقائي لبيانات الألعاب، الأغلفة، والخلفيات عبر SteamGridDB أو LocalDB.<br><br>🏆 **متتبع الإنجازات:** نظام مدمج لتتبع جوائز Xbox 360 مع واجهة منقسمة (Split-pane) أنيقة.<br><br>⚙️ **إعدادات متقدمة:** إعدادات مخصصة لكل لعبة، فحص عميق للملفات (abgx360)، وإدارة الباتشات.<br><br>🌍 **تعدد اللغات:** دعم كامل للغات المتعددة، بما في ذلك التخطيط من اليمين لليسار (RTL) للغة العربية.</div> |

## 🚀 Installation & Setup | التثبيت والإعداد

| How to Install | طريقة التثبيت |
| :--- | ---: |
| 1. Download the theme file from the Releases tab.<br>2. Extract the `NEX-metro` folder into the `systems` folder located inside your main **Xenia Dashboard** directory.<br>3. Launch the Xenia Dashboard program.<br>4. Go to **Settings > Themes**.<br>5. You will see the new theme there; select it to apply! | <div dir="rtl">1. قم بتحميل ملف الثيم.<br>2. استخرج المجلد `NEX-metro` بداخل مجلد `systems` الموجود في مسار برنامج **Xenia Dashboard** الأساسي.<br>3. قم بتشغيل برنامج Xenia Dashboard.<br>4. اذهب إلى **الإعدادات (Settings) > الثيمات (Themes)**.<br>5. سوف يظهر الثيم الجديد هناك، قم باختياره لتفعيله فوراً!</div> |
